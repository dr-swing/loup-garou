🐺 Fiches Loups-Garous de Pech

Comment jouer chaque rôle

Meneur
🐺

Loup-Garou

Loup-Garou
Objectif Éliminer tous les Villageois.
Comment jouer Chaque nuit, le Meneur appelle les Loups-Garous. Ils désignent collectivement une victime à dévorer.
🐺🐺

Grand Méchant Loup

Loup-Garou
Objectif Éliminer tous les Villageois.
Comment jouer La nuit, il dévore deux victimes (tant qu'aucun Loup-Garou n'a été éliminé).
🦠

Père des Loups (Loup-Garou Maudit)

Loup-Garou
Objectif Éliminer tous les Villageois.
Comment jouer La nuit, il peut choisir d'infecter sa victime au lieu de la dévorer. La victime devient Loup-Garou la nuit suivante. Il peut faire cela une fois par partie.
🐺❄️

Loup-Garou Blanc

Solitaire
Objectif Être le seul survivant du village.
Comment jouer La nuit, il dévore avec les Loups-Garous. Puis, une nuit sur deux, il tue un Loup-Garou en secret.
🏡

Villageois

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Aucun pouvoir. Participe aux débats et votes du jour pour identifier les Loups-Garous.
🏡🏡

Double Villageois

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Sa carte affiche un Villageois sur les deux faces. Tout le monde sait qu'il est un Villageois innocent.
🔮

Voyante

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Chaque nuit, le Meneur l'appelle. Elle choisit un joueur pour regarder sa carte.
🧙‍♀️

Sorcière

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer La nuit, le Meneur l'appelle. Elle possède 2 potions à utiliser une seule fois chacune : une de vie (sauve un joueur) et une de mort (tue un joueur). Elle peut les utiliser la même nuit.
🎯

Chasseur

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer S'il est dévoré ou lynché, il peut tuer un joueur de son choix avant de mourir.
👧

Petite Fille

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer La nuit, elle peut espionner les Loups-Garous (ouvrir légèrement les yeux). Si un Loup-Garou la voit, il peut la dévorer à sa place.
🛡️

Défenseur (Bouclier)

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Chaque nuit, le Meneur l'appelle. Il protège un joueur (y compris lui-même) des Loups-Garous. Il ne peut pas protéger deux fois le même joueur de suite.
👴

Ancien

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Les Loups-Garous doivent le dévorer deux fois pour l'éliminer. S'il est sauvé par la Sorcière, il ne récupère qu'une vie. Si le village le lynche, tous les Villageois perdent leurs pouvoirs jusqu'à la fin.
🤪

Idiot du Village

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer S'il est éliminé par les votes du village, il révèle sa carte et est épargné. Il ne peut plus voter. S'il est dévoré, il est éliminé normalement.
👯‍♀️

Deux Sœurs

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer La première nuit, le Meneur les appelle. Elles se reconnaissent mutuellement et peuvent coordonner discrètement leurs actions.
👨‍👨‍👦

Trois Frères

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer La première nuit, le Meneur les appelle. Ils se reconnaissent mutuellement et peuvent coordonner discrètement leurs actions (comme les Deux Sœurs, mais en 3).
🦊

Renard

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Chaque nuit, le Meneur l'appelle. Il choisit 3 joueurs voisins (dont un au centre). Si au moins un Loup-Garou est dans ce groupe, il peut réutiliser son pouvoir. Sinon, il le perd définitivement.
🐻

Domptrice d'Ours

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Chaque matin, si un Loup-Garou est assis à côté d'elle, son ours grogne (le Meneur fait un bruit de grognement). Les joueurs éliminés ne comptent pas.
⚖️

Juge Bègue

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer Une fois par partie, il peut organiser deux votes consécutifs sans débat entre les deux.
⚔️

Chevalier à l'Épée Rouillée

Villageois
Objectif Éliminer tous les Loups-Garous.
Comment jouer S'il est dévoré, un Loup-Garou est contaminé par son épée rouillée et meurt la nuit suivante.
💘

Cupidon

Solitaire
Objectif Gagner avec les amants (être les seuls survivants).
Comment jouer La première nuit, le Meneur l'appelle. Il choisit 2 joueurs à lier en amoureux (peut inclure lui-même). Si l'un meurt, l'autre se suicide. Les amants ne peuvent pas voter l'un contre l'autre.
🕵️‍♂️

Voleur

Solitaire
Objectif Gagner avec le rôle qu'il choisit.
Comment jouer La première nuit, le Meneur l'appelle. Il échange sa carte contre l'une des 2 cartes non distribuées (qui sont des Villageois simples, sauf si les 2 sont des Loups-Garous).
👗

Servante Dévouée

Solitaire
Objectif Gagner avec le rôle du joueur éliminé qu'elle choisit.
Comment jouer Avant que la carte d'un joueur lynché ne soit révélée, elle peut se révéler et prendre son identité. Elle joue avec cette nouvelle carte jusqu'à la fin. Elle ne peut pas utiliser ce pouvoir si elle est amoureuse.
🎭

Commédien

Solitaire
Objectif Gagner avec le camp qui remporte la partie.
Comment jouer Avant la partie, le Meneur choisit 3 cartes personnages (avec pouvoirs) et les place face visible au centre. Chaque nuit, l'Commédien peut utiliser le pouvoir de l'une de ces cartes (qui est ensuite retirée).
🧒

Enfant Sauvage

Solitaire
Objectif Rester un Villageois; Devenir Loup-Garou si son modèle meurt.
Comment jouer La première nuit, le Meneur l'appelle. Il choisit un modèle (un joueur). Tant que ce modèle est vivant, l'Enfant Sauvage reste un Villageois. Si son modèle meurt, il devient un Loup-Garou la nuit suivante.
🐕

Chien-Loup

Solitaire
Objectif Gagner avec le camp choisi.
Comment jouer La première nuit, le Meneur l'appelle. Il choisit d'être un Villageois simple ou un Loup-Garou pour toute la partie.
👼

Ange

Solitaire
Objectif Être lynché ou dévoré lors du premier tour.
Comment jouer Si le village le lynche ou les Loups-Garous le dévore lors du premier tour, il gagne la partie et la partie s'arrête. Sinon, il devient un Villageois simple pour le reste de la partie.
🎵

Joueur de Flûte

Solitaire
Objectif Enchanter tous les joueurs.
Comment jouer Chaque nuit, le Meneur l'appelle. Il enchante 2 nouveaux joueurs. S'il n'y a plus que des joueurs enchantés, il gagne. Les joueurs enchantés gardent leurs pouvoirs.
👤

Manipulateur Préjugé

Solitaire
Objectif Éliminer tous les joueurs de l'autre groupe.
Comment jouer Avant la partie, le Meneur divise le village en 2 groupes (ex : hommes/femmes, lunettes/pas lunettes). Il doit éliminer tous les joueurs du groupe opposé au sien.
🔮

Bohémienne

Solitaire
Objectif Gagner avec le camp qui remporte la partie.
Comment jouer Chaque nuit, le Meneur l'appelle. Elle peut poser une question à un joueur éliminé (via une carte Spiritisme). Le mort répond par "Ouiii" ou "Nooon".
